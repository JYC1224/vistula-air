# Vistula Air｜航空經營誌

## 方向與玩家體驗

玩家接手以華沙蕭邦機場 WAW 為基地的虛構航空公司 Vistula Air。背景為現代，透過營運席位、航線圖、機隊資料與員工對話工作。時間由玩家按「下一營運日」推進，讓自主學習者有時間研究資料、比較方案與補救。

主線是接受航線委託、選擇合適機型、購買或租賃機隊、安排維修並投入營運。完成六個階段的委託後，公司由歐洲區域營運者成長為跨洲航空公司；通關後仍可經營。

已確認需求：真實機場與地理、Airbus／Boeing／Embraer、細分子型與引擎、成熟玩家、自主學習、公司經營者視角、工作決策式學習。未逐項指定的細節由本版採取中等難度與可補救的設計。

## 可觀察的學習目標

| 目標 | 遊戲行動 | 回饋與證據 |
| --- | --- | --- |
| 區分家族、子型、世代與引擎配置 | 查閱實機照片、對照機型資料、比較採購標的 | 資料庫列出本型與相近型差異；工作紀錄保留實際使用的機型 |
| 理解區域機、窄體與廣體的定位 | 配對航線需求、座位、班次與航程 | 顯示載客率、營收、成本與未滿足需求，改變航線條件後再次運用 |
| 解釋飛機基本結構與飛行受力 | 在機庫查看主翼、引擎、尾翼與起落架 | 可點擊結構圖、簡潔原理解說、機務人員的工作脈絡 |
| 理解維修與可用運能的取捨 | 決定維修時機、暫停或更換派機 | 維修占用營運日；結果報告分開呈現停場、恢復狀況與收入影響 |

資料查閱次數、遊戲高分或通關不直接當作理解的證明。營運情境提供應用證據；完整保留與遷移評估應在後續加入未見過的航線條件與延後任務。

## 核心循環

1. 在董事會委託與地圖上選擇目的地。
2. 閱讀距離、模擬市場需求、票價與任務條件。
3. 比較機型的配置座位、航程、世代、引擎與營運成本。
4. 選擇現有飛機，或從市場購買／租賃；設定往返班次與服務定位。
5. 預覽方案的運能、載客率與收支，再確認開航。
6. 安排保養，主動推進一天。
7. 閱讀結果、處理機務訊息、修正方案；達成委託並解鎖新市場。

## 首版內容

- 起始資金 €8,400,000、三架既有飛機及一條 WAW–VIE 航線。
- 八款可查閱機型：E190、E195-E2、A320-200、A320neo、A321XLR、737-800、737 MAX 8、787-9。
- 六個委託目的地：CPH、FCO、LHR、KEF、DXB、JFK。
- 歐洲與跨洲地圖、機型資料庫、兩機對照、購買與租賃、機庫維修、日結報告、公司進度與本機存檔。
- 員工 Marta（營運）、Tomasz（機務）與 Anna（機隊）提供情境與選用式建議。

機型資料庫記錄公開參考航程與尺寸、示例座位與引擎選項。機身照片的航空公司塗裝只作辨識參考，不代表遊戲公司。不能只憑塗裝、翼尖或單一特徵判定子型；資料冊會提醒核對型號與配置。

## 規則與難度

- 每架飛機同時投入一條航線；每條航線可安排一或兩個往返／日，受每日飛機使用時數上限限制。複雜多航段輪調留給後續版本。
- 航線距離由真實機場座標計算大圓距離；開航檢查另加遊戲航程餘裕。這是遊戲篩選，不是實際飛航簽派或燃油計算。
- 市場需求、票價、購租價格、油耗費率、維修指標與成本皆為平衡用模擬數值；沒有假稱為即時航空公司數據。
- 實際運送人數受座位、班次、需求與服務定位限制；空位不產生收入。選大飛機不必然比較有利。
- 營運逐步降低維護指標；過低時系統停止該機派飛。保養需付費與停場，維修中的飛機不能執飛。
- 錯誤以可讀的原因與可補救結果呈現；沒有隱藏答題判分。任務沒有緊迫倒數，允許更換派機與暫停航線。
- 公司資金不足時提供有代價的復甦機會，避免學習被一次失誤永久阻斷。
- 玩家完成任務獲得資金與聲望。獎勵依運送、載客率與收支結果，而非點擊速度。

## 素材先行

先確認素材後才製作 MVP。素材清單與來源見 [ASSETS.md](ASSETS.md)；公開授權與圖片署名隨遊戲放在 `public/assets/licenses/`，遊戲內也提供來源視窗。

選用真實機型照片與真實地理底圖，以維持辨識與地理學習；Kenney Interface Sounds 用於操作回饋。介面標誌、人物肖像與結構示意圖使用專案原創 SVG。

## 分階段實作計畫

### 0：素材挑選與內容校核

1. 依目標篩選照片，逐筆核對確切機型、作者與授權；排除把 E195 誤當 E190 的搜尋結果。
2. 下載地圖、機場座標、字型與 Kenney 音效，建立來源表。
3. 核對機型規格與基礎原理的官方參考資料；分開標記公開事實與遊戲模型。

完成條件：MVP 所需素材可在本機載入，來源與授權完整。

### 1：MVP——先完成一個可玩的營運循環

1. 建立純資料營運模型、起始公司、現有機隊與 WAW 基地。
2. 實作 CPH／FCO 航線的派機、班次、預估收支、一天結算與委託進度。
3. 接入地圖與工作面板，玩家能從接案一路完成委託。
4. 驗證航程、飛機占用、資金、維修停場與收支結算的一致性。

完成條件：不靠開發者修改資料，能完整走完「比較—派機—營運—結果—調整」並完成首個委託。

### 2：機隊與辨識迭代

加入八款機型的照片資料冊、家族篩選、兩機比較、購買／租賃，以及機隊狀態視圖。加入長短機身、世代與引擎的解釋，擴大可選方案。

### 3：經營與學習內容迭代

加入維修安排、互動結構圖、員工訊息、更多歐洲航線與跨洲任務。把停場、空位成本和航程不足的原因接到結果回饋，讓同一概念在不同條件下反覆使用。

### 4：體驗與平衡迭代

完成本機存檔、音效開關、鍵盤操作、窄螢幕排版、明確的失誤回饋與完整通關。以實際操作檢查過度強勢的選項、卡關、溢位與資料錯誤。

### 後續擴充

多航段輪調與時刻表、更多 A319／A321／A330／A350／737／777／E-Jet 子型、精細引擎配置、天氣與機場限制、真實成本來源及條件範圍、延後學習任務。擴充前先確認現有學習循環可用。
