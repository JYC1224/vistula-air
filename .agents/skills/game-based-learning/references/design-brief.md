# 遊戲設計簡報

在使用者要求遊戲構想、設計規格或需要先對齊團隊時，選用以下欄位組成一份精簡簡報。每個欄位都應幫助玩家經驗、學習目標或實作決策；不適用的欄位可省略。

## 可複用模板

### 概要

- **遊戲暫名與一句話概念：**
- **目標玩家與情境：**年齡或學習階段、先備知識、個人／團隊、使用裝置與時間。
- **內容範圍：**遊戲教什麼、刻意不涵蓋什麼；列出重要模型假設或待確認事實。
- **學習目標：**「在＿＿條件下，玩家能＿＿；以＿＿作為可觀察證據。」目標要描述可做的事，不只寫「認識／了解」。
- **遊戲目標：**玩家在遊戲內要完成什麼、如何判定成功。

### 玩法與學習連結

| 學習目標 | 玩家必須做的事 | 機制／狀態變化 | 回饋與下一次機會 | 學習證據 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |

- **核心循環：**玩家先＿＿，再＿＿，之後看到＿＿，最後＿＿。
- **狀態、行動與規則：**列出玩家需要追蹤的狀態、可用行動，以及每個行動如何依規則改變狀態。
- **關鍵抉擇與取捨：**選項為何不同？會影響哪些短期／長期結果？玩家能看到哪些資訊？
- **回饋、獎勵、評量：**分開說明各自的用途，並檢查高分策略是否仍促使玩家運用學習目標。
- **進度與支援：**新挑戰如何加入、何時提供提示、怎麼淡出支援、失敗後怎麼回看或重試。
- **無障礙與公平參與：**文字與圖示可讀性、顏色替代訊號、控制方式、時間壓力、合作角色的參與機會。

### 製作與評估

- **媒介與必要功能：**桌遊、網頁、手機或其他媒介；只列出支持玩法所需的功能。
- **最小可玩切片：**核心場景、主要選擇、結果回饋及一個可重試的流程。
- **原型問題：**這次試玩要確認哪個明確問題？觀察什麼行為或理由能回答它？
- **成效證據：**分開列出參與、當下學習、延後保留、遷移；只保留此設計需要的項目。
- **假設、限制與下一步：**列出待確認內容、時間／工具限制，以及原型後的決策。

## 依學習行動選玩法的參考例

### 系統與資源決策

若目標是讓玩家比較方案、理解累積效果，可設計多回合的資源管理任務：玩家查看供需與成本、預測方案後果、做選擇，再比較各回合的存量與支出。保留模型假設與完整結果，讓玩家能解釋短期與長期差異。單一終局分數可能掩蓋取捨，因此可同時呈現相關結果並要求說明理由。

### 資訊查證與證據推論

若目標是判斷消息是否有足夠證據，可讓玩家檢查來源、日期、原始資料與最新更正，再決定是否採取行動。錯誤後的回饋指出缺少哪類證據或哪個查核步驟，並以條件不同的新案例讓玩家再次運用方法；不要只靠記住上一題的答案通關。

### 記憶練習與獎勵

詞彙辨識或術語回想可以透過答題推進、點數或徽章形成簡單遊戲化練習。若更高層次的目標是解釋概念或遷移知識，另安排需要解釋、比較或處理新條件的任務，並蒐集相應證據。
